Algorithmic Overview

This project demonstrates core algorithmic paradigms taught in Design and Analysis of Algorithms (DAA), including searching strategies, divide-and-conquer sorting, and constraint-based filtering for alternative transit routing.

1. Linear Search (Unsorted Service Lookup)

Used when searching through newly added or unsorted transit services by route name or description.

Time Complexity: Best: $O(1)$, Average: $O(N)$, Worst: $O(N)$

Space Complexity: $O(1)$

2. Binary Search (Sorted Service ID Lookup)

Used for rapid service retrieval by Service ID. Requires the dataset to be strictly sorted beforehand.

Time Complexity: Best: $O(1)$, Average: $O(\log N)$, Worst: $O(\log N)$

Space Complexity: $O(1)$ (Iterative implementation)

3. Merge Sort (Occupancy Sorting & Ranking)

A stable divide-and-conquer sorting algorithm used to order transport services by occupancy percentage from lowest to highest.

Time Complexity: Best / Average / Worst: $O(N \log N)$

Space Complexity: $O(N)$ for auxiliary temporary arrays during merging.
