Design and Analysis of Algorithms (DAA) Implementation Details

This project integrates four fundamental algorithmic paradigms to deliver efficient public transport estimation and routing.

1. Searching (Linear Search & Binary Search)

Purpose: Locate specific transit services by route name or unique Service ID.

How it works: Linear Search scans unsorted route strings in $O(N)$ time. Binary Search partitions pre-sorted service IDs in logarithmic time $O(\log N)$.

Time Complexity: Linear Search $O(N)$, Binary Search $O(\log N)$. Space Complexity: $O(1)$.

2. Sorting (Merge Sort)

Purpose: Rank transport services by occupancy percentage from least crowded to most crowded.

How it works: Divides the service array recursively into halves, sorts them, and merges them stably.

Time Complexity: $O(N \log N)$ across all cases. Space Complexity: $O(N)$.

3. Graph Algorithm (Dijkstra's Shortest Path)

Purpose: Compute the fastest travel-time route between transit stops.

How it works: Models stations as vertices and travel times as non-negative edge weights, using a priority queue to greedily find the minimum travel duration.

Time Complexity: $O((V + E) \log V)$. Space Complexity: $O(V + E)$.

4. Dynamic Programming (Bounded-Leg Minimum Travel Cost)

Purpose: Determine the optimal route minimizing monetary travel cost within a maximum connection constraint ($K$ legs).

How it works: Utilizes state tabulation $dp[legs][stop]$ to build optimal subproblem solutions without redundant recalculations.

Time Complexity: $O(K \cdot (V + E))$. Space Complexity: $O(K \cdot V)$.
