Algorithm & Complexity Reference Guide

Merge Sort

Manually implemented divide-and-conquer sorting algorithm used to sort transport stops by crowd counts.

Time: $\mathcal{O}(N \log N)$ | Space: $\mathcal{O}(N)$

Binary Search

Logarithmic search executed on sorted stop IDs to retrieve specific station metrics instantly.

Time: $\mathcal{O}(\log N)$ | Space: $\mathcal{O}(1)$

Dijkstra's Algorithm

Computes shortest-distance paths and crowd-cost-optimized routes across graph adjacency lists.

Time: $\mathcal{O}((V + E) \log V)$ | Space: $\mathcal{O}(V + E)$

Dynamic Programming

Tabulates future time-slot penalties to recommend the optimal departure time minimizing waiting and congestion costs.

Time: $\mathcal{O}(N^2)$ | Space: $\mathcal{O}(N)$
